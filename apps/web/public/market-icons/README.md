# Market icons

Every PNG, WebP, JPG or GIF in this folder shows up in the icon picker on the propose / edit forms.
To add one: drop the file in here (square-ish, ~256px is plenty) and restart or redeploy.
The file name is the label (`hack-logo.png` shows as "hack logo") and is what gets saved on a market,
so don't rename or delete a file that markets already use.
